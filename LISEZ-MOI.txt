LE GRAND PILLAGE — SQL MYSTÈRE FRANÇAIS

Enquête SQL pédagogique : retrouvez les pilleurs du magasin
Électro+ (Joinville-sur-Requête, 17 octobre 2026), puis...
peut-être que l'enquête ne sera pas finie pour autant.

POUR JOUER (sur n'importe quel PC Windows) :
1. Décompressez ce zip dans un dossier (double-clic > Extraire tout).
2. Double-cliquez sur Demarrer-le-site.bat
   -> une fenêtre noire s'ouvre (le serveur), et votre navigateur
      affiche automatiquement le site.
3. Si le navigateur ne s'ouvre pas : tapez http://localhost:8471

PRÉREQUIS : Python (gratuit : https://www.python.org/downloads/ ,
cocher "Add python.exe to PATH" à l'installation).
Aucune connexion internet n'est nécessaire pour jouer.

POUR PARTAGER LE JEU À QUEQU'UN :
Envoyez-lui simplement ce fichier zip.
