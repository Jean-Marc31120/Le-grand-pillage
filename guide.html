Le crime

Un magasin pillé en marge du cortège

Le 17 octobre 2026, pendant que la ville manifestait contre la vie chère, le magasin Électro+ de Joinville-sur-Requête a été pillé. Le commissariat stocke tous ses rapports dans une base de données. Votre mission : retrouver les coupables, uniquement avec des requêtes SQL.

Étape 1 · Bases de données

Des tables, des colonnes, des lignes

Une base de données relationnelle stocke l'information dans des tables, un peu comme des feuilles de calcul. Chaque table a des colonnes (des caractéristiques) et des lignes (des enregistrements).

Étape 2 · SELECT

Demander des données

SELECT * FROM table signifie : « renvoie toutes les colonnes (*) de toutes les lignes ». Ajoutez LIMIT pour ne pas faire déferler la table entière à l'écran.

Étape 3 · WHERE

Filtrer les lignes

WHERE garde uniquement les lignes qui vérifient une condition. Les dates sont écrites en nombres AAAAMMJJ (le 17 octobre 2026 devient 20261017). On combine des conditions avec AND, et les textes s'écrivent entre guillemets : 'pillage'.

Lisez la description obtenue : deux témoins y sont décrits. C'est votre première vraie piste.

Étape 4 · ORDER BY

Trier pour trouver

ORDER BY colonne DESC trie du plus grand au plus petit (ASC fait l'inverse). Avec LIMIT 1, vous obtenez le « maximum ». Le rapport dit que le témoin n°1 habite la dernière maison de la rue des Alizés : la table personne a une colonne adresse_numero…

Est-ce bien la bonne personne ? Le rapport précise qu'elle possède un chat nommé Capitaine NUL. Les interrogatoires sont dans la table interview, reliée par personne_id.

« Capitaine NUL ! » — c'est bien elle. Dans son récit se cachent deux indices : une plaque d'immatriculation et une salle de sport.

Étape 5 · JOIN

Relier les tables entre elles

Chaque table ne contient qu'un morceau de la vérité. Les tables communiquent grâce aux clés étrangères : une colonne qui contient l'id d'une ligne d'une autre table. JOIN … ON soude deux tables ligne par ligne, et WHERE filtre le résultat combiné.

Reprenez l'indice de la camionnette : plaque de 7 caractères, commençant par BK et contenant 94. Cette info est dans permis_conduire, pas dans personne.

Attention : plusieurs personnes correspondent ! La plaque seule ne suffit pas. C'est là qu'intervient le second indice : la salle de sport La Fonte d'Acier. Les deux pilleurs y sont allés le matin du 17 octobre avant 12 h, avec un abonnement or.

Vous tenez les coupables : recoupez les deux listes (la plaque et la salle), puis confirmez avec leurs interview. Le récit de l'un d'eux contient une révélation de taille.

À vous de jouer

Bonne chance, détective

Vous savez lire un rapport, retrouver un témoin, interroger les gens et relier les tables : c'est tout ce qu'il faut pour toute l'enquête. Les indices restants sont cachés dans les transcriptions et les pointages de La Fonte d'Acier : recoupez, joignez, filtrez, et les coupables tomberont.
